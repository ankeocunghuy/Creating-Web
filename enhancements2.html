These are the two enhancements I implemented for Assignment 2. Each item shows where it’s used, what & why, a brief how (with code), and a page where the marker can try it live.

1) Payment Input Auto-Formatting (Card Number & Expiry)

Where: payment.html · File: scripts/enhancements.js (function enhancePayment())

What & Why: While the user types, the card number is grouped for readability (Visa/MasterCard 4-4-4-4, AmEx 4-6-5) and the expiry auto-inserts the dash (MM-YY). This lowers input mistakes and speeds up data entry. It’s a progressive enhancement: the core validation still runs in JavaScript and strips spaces before submit.

// In enhancements.js
const typeEl = $('#card_type'), numEl = $('#card_number'), expEl = $('#card_expiry');

// Group digits: AmEx 4-6-5, otherwise 4-4-4-4
function formatNumber(){
  const t = typeEl?.value || "";
  const d = (numEl.value || "").replace(/\D/g, "").slice(0, t === "amex" ? 15 : 16);
  numEl.value = (t === "amex")
    ? d.replace(/(^\d{0,4})(\d{0,6})(\d{0,5}).*/, (_,a,b,c) => [a,b,c].filter(Boolean).join(" "))
    : d.replace(/(\d{4})(?=\d)/g, "$1 ").trim();
}

// Insert dash → "MM-YY"
function formatExpiry(){
  const d = (expEl.value || "").replace(/\D/g, "").slice(0,4);
  expEl.value = d.length >= 3 ? d.slice(0,2) + "-" + d.slice(2) : d;
}

Evidence: Open Payment and type a Visa/MasterCard/AmEx number and an expiry date — spacing and the dash appear automatically.

2) Accessible Error Focus & Scroll

Where: enquire.html & payment.html · Files: scripts/part2.js, scripts/enhancements.js

What & Why: When validation fails, the page scrolls to the error box and keyboard focus moves to the first invalid field. The invalid controls are flagged with aria-invalid="true" and the first one is recorded in data-first-invalid. This makes fixing errors faster and improves screen-reader usability.

// part2.js — flag first invalid and remember it for the enhancer
let firstInvalidSel = null;
function flag(sel){ const el = document.querySelector(sel);
  if (el){ el.setAttribute("aria-invalid","true"); if (!firstInvalidSel) firstInvalidSel = sel; }
}
errors.dataset.firstInvalid = firstInvalidSel || "";

// enhancements.js — scroll and focus when the error box updates
const sel = box.dataset.firstInvalid;
if (sel && form.querySelector(sel)?.focus) form.querySelector(sel).focus();
else form.querySelector("[aria-invalid='true']")?.focus();

Evidence: On Enquire, leave “Suburb” empty and click Pay Now — the page scrolls and focus lands on the Suburb field (the first failing control). Repeat on Payment with an invalid card number.
